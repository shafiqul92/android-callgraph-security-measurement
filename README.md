# Android static call graphs: security-oriented measurement (paper artifact)

This repository accompanies our work on **benchmark-to-reality transfer** for Android **static call-graph** tools, evaluated against **dynamic** (instrumented) execution with **lightweight security tagging** and downstream **privacy** / **malware–evasion observability** proxies.

## Status

**Initial public skeleton.** Scripts, frozen tables, and full reproduction instructions will be added for camera-ready / artifact evaluation. The authoritative measurement code and derived datasets currently live in a private workspace and will be published or linked here as permitted by the venue and data agreements.
